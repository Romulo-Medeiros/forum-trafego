# Weekly Review Checklist

Used during `*weekly-report` to keep the digest disciplined.

## Data completeness
- [ ] 7d and 28d windows both pulled (for trend context)
- [ ] Daily-check logs for each of the 7 days attached
- [ ] Target vs actual computed per campaign (not just overall)
- [ ] Creative-level metrics pulled (top 3 winners, top 3 losers)

## Honesty
- [ ] Biggest miss is named explicitly in executive summary (no burial)
- [ ] Any tracking breakage in the week is called out
- [ ] "We don't know yet" is said when statistical noise is real (<30 conversions)

## Decisions
- [ ] Every recommendation has expected impact (in R$ or %)
- [ ] Every HITL decision has a deadline (not open-ended)
- [ ] Kill list has explicit "will revisit by YYYY-MM-DD" where applicable

## Creative hygiene
- [ ] Fatigue flagged on anything with freq > 3.0 and 7d decline
- [ ] @criat briefed for next week's refresh (specific angles, not generic)
- [ ] Winners identified for scaling (not "maybe" — yes or no)

## Next week plan
- [ ] 1-3 tests planned (with hypothesis + success criteria)
- [ ] 1-3 scales planned (with increment + rollback trigger)
- [ ] 1-3 kills planned (with evidence + final cost)

## Communication
- [ ] Report readable in ≤ 5 min (if longer, trim)
- [ ] Numbers are in the report (not attached, not deferred)
- [ ] One clear ask from the human at the end (or explicit "no ask this week")

---

**Good report = you can skip the meeting. Bad report = you schedule one.**
